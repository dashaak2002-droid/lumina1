# Lumina — Life OS для женщин

Одно спокойное приложение вместо десяти: **планер, привычки, цели, сферы жизни, заметки и AI-помощник**.
Mobile-first, тёплая минималистичная палитра, русский интерфейс.

> Это работающий MVP: открывается в браузере и на телефоне, данные сохраняются, основные сценарии
> (онбординг, Quick Add, планер, привычки, цели, заметки, чат с AI) работают по-настоящему.
> Без ключа AI приложение работает в **демо-режиме** — этого достаточно, чтобы показать продукт.

## 1. Что нужно установить (один раз)

Нужна всего одна программа — **Node.js** (версия 18.18 или новее, лучше LTS).

1. Откройте <https://nodejs.org> и скачайте версию **LTS**.
2. Установите, как обычную программу (везде «Далее»).
3. Проверьте: откройте Terminal и введите `node -v` — должно показать номер версии (например, `v22.12.0`).

**Как открыть Terminal:**
- **Mac:** нажмите `Cmd + Пробел`, введите «Terminal», нажмите Enter.
- **Windows:** нажмите клавишу Windows, введите «PowerShell», нажмите Enter.

Редактор кода устанавливать необязательно. Если захотите смотреть файлы — подойдёт бесплатный VS Code.

## 2. Запуск (5 команд)

Распакуйте папку проекта (`lumina`) например на рабочий стол. Затем в Terminal:

```bash
# 1. перейти в папку проекта (подставьте свой путь)
cd ~/Desktop/lumina          # Windows: cd $HOME\Desktop\lumina

# 2. установить зависимости (занимает 1–3 минуты, нужен интернет)
npm install

# 3. создать файл настроек
cp .env.example .env.local   # Windows: copy .env.example .env.local

# 4. запустить
npm run dev
```

Откройте в браузере **<http://localhost:3000>** — вы увидите онбординг. 🎉

Остановить приложение: в Terminal нажмите `Ctrl + C`.
В следующий раз достаточно `cd …` и `npm run dev` (шаги 2–3 повторять не нужно).

## 3. Как открыть на телефоне

**Вариант А — по домашнему Wi-Fi (быстрее всего).** Компьютер и телефон должны быть в одной Wi-Fi сети.

1. Узнайте IP-адрес компьютера:
   - Mac: `ipconfig getifaddr en0`
   - Windows: `ipconfig` → строка «IPv4-адрес» (например, `192.168.1.25`)
2. На телефоне откройте в браузере `http://ВАШ_IP:3000` (например, `http://192.168.1.25:3000`).
3. Чтобы приложение было на экране «Домой»: Safari → «Поделиться» → «На экран Домой»; Chrome → меню → «Добавить на главный экран».

Если страница не открывается — проверьте, что устройства в одной сети, и разрешите Node.js в брандмауэре.

**Вариант Б — публичная ссылка для инвестора или первых пользователей.** Бесплатно, через Vercel:

1. Загрузите проект на GitHub (аккаунт на github.com → New repository → загрузить файлы).
2. На <https://vercel.com> войдите через GitHub → «Add New → Project» → выберите репозиторий → Deploy.
3. В настройках проекта Vercel → **Settings → Environment Variables** добавьте ключ AI (см. раздел 4).
4. Получите ссылку вида `https://lumina-xxxx.vercel.app` — её можно открыть на любом телефоне.

> Важно: в MVP данные хранятся в браузере конкретного устройства. На другом телефоне будет свой «чистый» экземпляр.
> Для синхронизации между устройствами нужна база данных — см. раздел 7.

## 4. Подключение настоящего AI (по желанию)

Без ключа AI-помощник работает в демо-режиме: понимает фразы вроде «Маникюр завтра в 16:00»,
«Помоги распланировать неделю», «Расставь приоритеты», «Проанализируй неделю».

Чтобы AI отвечал на любые вопросы и давал персональные советы:

1. Получите ключ API: Anthropic (Claude) — <https://console.anthropic.com> или OpenAI — <https://platform.openai.com>.
   (Доступ к API платный, оплата по использованию; для тестов хватает нескольких долларов.)
2. Откройте файл `.env.local` (создан на шаге 3) и впишите ключ:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
   или `OPENAI_API_KEY=sk-...`
3. Перезапустите приложение (`Ctrl + C`, затем `npm run dev`).
4. В приложении: **Профиль → AI-помощник** покажет, что AI подключён.

**Безопасность:** ключ хранится только в `.env.local` и используется только на сервере (`app/api/ai/route.ts`).
В браузер он никогда не попадает. **Не отправляйте `.env.local` никому и не загружайте на GitHub** (он уже в `.gitignore`).

Как AI связан с приложением: чат отправляет в модель краткую выжимку ваших задач, привычек и целей
(`lib/ai-context.ts`), а модель отвечает текстом и **списком действий** («добавь событие», «перенеси задачу»,
«добавь шаги к цели»). Приложение проверяет эти действия (`lib/actions.ts`) и применяет их.

## 5. Что внутри

| Раздел | Что умеет |
|---|---|
| **Онбординг** | 4 коротких шага: имя и возраст → приоритетные сферы → что улучшить и главная цель → нужные функции. Затем собирается персональный дашборд. |
| **Home / Сегодня** | Приветствие, дата, AI-подсказки, события и задачи дня, привычки, цели, сферы жизни. Quick Add сверху. |
| **Quick Add** | Пишете «Маникюр завтра в 16:00» — приложение понимает тип (задача/событие/заметка), дату, время, сферу, повтор и срочность. Можно поправить тип одним нажатием. |
| **Planner** | День / Неделя / Месяц / Списки. Задачи, события, повторяющиеся задачи («Каждый понедельник…»), напоминания, списки (например, «Покупки»). |
| **AI** | Чат: планирует неделю, расставляет приоритеты, анализирует неделю, добавляет события и задачи по обычной фразе. |
| **Life → Сферы** | 8 сфер жизни с оценкой состояния; в каждой — задачи, цели, привычки. |
| **Life → Цели** | Название, описание, срок, этапы, прогресс, связанные задачи; кнопка «Разбить на шаги с AI». |
| **Life → Привычки** | Отметка на сегодня, серии (streak), недельный прогресс, статистика за 30 дней. |
| **Life → Заметки** | Brain Dump: приложение определяет, чем похожа запись, и предлагает перенести её в задачи, календарь или цели. |
| **Профиль** | Имя, приоритеты, видимость блоков, статус AI, напоминания, резервная копия данных, демо-данные. |

### Технологии (и почему)

- **Next.js 14 + React + TypeScript** — самый распространённый стек: легко найти разработчиков, один проект для интерфейса и сервера.
- **Свой CSS без библиотек** (`app/globals.css`) — минимум зависимостей; дизайн меняется правкой переменных вверху файла (`--accent`, `--bg`, …).
- **localStorage** вместо базы данных — для MVP не нужно ничего настраивать.
- **lucide-react** — иконки.

## 6. Как менять самое частое

| Что хочется | Где править |
|---|---|
| Цвет акцента, фон, скругления | `app/globals.css`, блок `:root` в самом начале |

## 7. Как развивать дальше (дорожная карта)

Всё, что упрощено в MVP, помечено ниже — архитектура уже готова к развитию.

1. **Аккаунты и синхронизация между устройствами.** Сейчас авторизации нет (данные локальные, это сознательно: меньше трения для первых тестов).
   Следующий шаг — Supabase: выполнить `db/schema.sql`, подключить Supabase Auth и заменить три функции в `lib/storage.ts` на запросы к базе. Остальной код менять не придётся.
2. **Push-напоминания при закрытом приложении.** Сейчас уведомления работают, пока приложение открыто (`lib/reminders.ts`). Для настоящих push нужен service worker + Web Push.
3. **Умный Quick Add через AI.** Сейчас фразы разбирает правило-ориентированный парсер (быстро, бесплатно, офлайн). Можно отправлять сложные фразы в AI и получать то же самое структурированно — каркас действий уже есть (`lib/actions.ts`).
4. **Автоклассификация заметок через AI** — сейчас простые правила (`classifyNote` в `lib/parser.ts`).
5. **Здоровье и финансы глубже:** трекер цикла/сна, бюджет по категориям — как отдельные модули в «Жизни».
6. **Ограничение запросов к AI** (rate limit) и счётчик расходов перед публичным запуском — иначе открытая ссылка может «сжечь» ваш лимит API.
7. **Повторяющиеся события** (сейчас повторяются задачи, события — разовые).
8. **Мультиязычность** — все тексты сейчас на русском, прямо в компонентах.

## 8. Частые проблемы

| Проблема | Решение |
|---|---|
| `npm: command not found` | Node.js не установлен или Terminal открыт до установки — закройте и откройте заново. |
| `npm install` долго «висит» | Нормально до 3–5 минут. Если ошибка сети — проверьте интернет/VPN и повторите. |
| Порт 3000 занят | `npm run dev -- -p 3001`, затем открыть `http://localhost:3001`. |
| На телефоне не открывается | Одна и та же Wi-Fi сеть? Брандмауэр разрешает Node.js? Адрес именно `http://IP:3000`. |
| Шрифты выглядят «простыми» | Шрифты подгружаются из Google Fonts — нужен интернет. Без него включится запасной шрифт. |
| Хочу начать с чистого листа | Профиль → «Сбросить приложение». |
| AI «Демо-режим», хотя ключ вписан | Ключ в `.env.local` (не `.env.example`), без кавычек и пробелов; приложение перезапущено. |
